# StockPilot — Smart Inventory & Sales Analytics

StockPilot is a Java-based inventory management application designed to manage products, suppliers, users, and stock transactions through a web interface.

## Features

- User registration and authentication
- Role-based access control
- Product management
- Supplier management
- Stock In / Stock Out
- Transaction management
- Product search and category filtering
- Inventory tracking
- REST API backend
- Responsive web interface

## Technology Stack

- Java 21
- Spring Boot
- Spring Data JPA
- Spring Security
- Hibernate
- H2 Database
- HTML5
- CSS3
- JavaScript
- Maven
